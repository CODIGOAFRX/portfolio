# Awesome DESIGN.md

Each folder in `design-md/<brand>/DESIGN.md` is a plain-text design system extracted from a real
website: tokens (colors, type, spacing, radii), component rules and the reasoning behind them.
Source: [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see LICENSE).

## How to use it on this project

1. Read the brief first. This portfolio is an editorial, black-and-white site (Georgia serif headlines,
   Arial body, one red accent `#e5322d`) with scroll-driven scenes. References must fit that language,
   not replace it.
2. Pick at most two or three references whose language is close to the decision at hand. Good matches
   for this site: `vercel`, `linear.app`, `apple`, `claude`, `raycast`, `resend`, `theverge`, `wired`.
3. Read only the relevant parts of those files (tokens, typography, spacing, the component in question).
4. Borrow principles and proportions, never brand identity: no copied logos, wordmarks, brand colors or
   signature gradients.
5. State in one line which reference informed the decision and why.
