Proyecto destacado / ERP para pymes

PERA ERP

Todo el negocio, mucho más claro.

Un ERP completo para pymes que funciona en el navegador: presupuestos, facturas con Veri*Factu, cobros, compras, contabilidad, TPV y almacén desde el móvil.

Nace para renovar DimproCristalWin, un ERP en Visual FoxPro, trayendo su comportamiento opción por opción a una arquitectura moderna.

pedrogomez.dev/proyecto/pera-erp/appDemo abierta

  • Del presupuesto a la factura

    Presupuesto, albarán y factura enlazados, sin volver a teclear nada.

  • Veri*Factu propio

    Registro, huella encadenada y QR en cada factura, remitidos solos a la AEAT.

  • Cobros y contabilidad

    Recibos, remesas y caja, y la actividad lista para asentar.

  • Tienda y almacén

    TPV con ticket de 80 mm y almacén con escáner desde el móvil.

  • 8servicios, cada uno con su base de datos
  • 764pruebas automáticas entre servidor e interfaz
  • 102migraciones de base de datos
Sistema
Pasarela y siete servicios independientes, multiempresa por token, facturas encadenadas y remitidas a la AEAT, y una demo con datos inventados en la que se entra sin registro.
Stack
Java 21 · Spring Boot 4.1 · Spring Cloud Gateway · PostgreSQL · Flyway · React 19 · TypeScript · Vite
