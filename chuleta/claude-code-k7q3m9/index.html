Arrancar en PowerShell

Lánzalo dentro de la carpeta del proyecto: lee su CLAUDE.md y sus skills.

› claudeAbre la sesión en la carpeta actual
› claude "petición"Arranca con una primera petición
› claude -cRetoma la última conversación
› claude -rElige qué conversación retomar
› claude -p "pregunta"Responde y sale, sin abrir sesión
› claude --model opusArranca con un modelo concreto
› claude updateActualiza Claude Code

¿Aún no escribe claude? Úsalo sin instalar:

npx.cmd -y @anthropic-ai/claude-code@latest

O instálalo una vez desde tu propia terminal:

npm.cmd install -g @anthropic-ai/claude-code

Flujo para una web tuya

El orden importa: plan, implementación, auditoría y revisión.

  1. cd portfolio y luego claudeDesde la carpeta del repo
  2. Shift+Tab hasta el modo planExplica qué quieres; aún no toca nada
  3. Aprueba el planLo implementa
  4. /impeccable auditComprueba escritorio 1440×900 y móvil 390×844
  5. /impeccable polishPasada final
  6. /code-reviewY después el commit

Nada coincide con esa búsqueda.

Las skills de plugin se escriben /plugin:skill. Si no recuerdas un nombre, escribe / y unas letras.
